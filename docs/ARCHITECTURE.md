# «Скрудж Макдак» — архитектура

## Цель

Единая барахолка в Telegram и ВКонтакте. Существующий VK Callback API и SQLite-код сохраняются; Telegram подключается как отдельный адаптер к общей базе и общим сервисам. Новая функциональность добавляется совместимо, без сброса текущей базы данных.

## Компоненты

- **VK adapter** — VK Callback API, сообщения сообщества и публикации на стене.
- **Telegram adapter** — Telegram Bot API, onboarding, управление подпиской и административные действия.
- **Application services** — модерация, управление объявлениями, рассылки, жалобы, роли и журнал действий.
- **SQLite storage (current)** — существующая DATABASE_PATH; таблицы Telegram и рассылок добавляются миграционно через CREATE TABLE IF NOT EXISTS.
- **Broadcast delivery** — кампания, подтверждение администратором, поочерёдная отправка, запись результата по каждому получателю.
- **Admin access** — роли VK и Telegram настраиваются отдельными списками ID в .env. Числовые ID двух платформ не считаются взаимозаменяемыми.

## Поток объявления

1. Пользователь создаёт черновик в одном из адаптеров.
2. Объявление сохраняется со статусом moderation.
3. Общий сервис модерации проверяет роль администратора и текущий статус.
4. После одобрения адаптер публикации размещает объявление на доступных платформах.
5. Результаты доставки сохраняются отдельно для повторных попыток без создания дубликатов.

## Рассылки

Администратор выбирает тип: важная новость, новости проекта, новые товары или другая рассылка. Перед отправкой показываются предпросмотр и аудитория. Отправка доступна только пользователям, которые сами начали взаимодействие с соответствующим ботом; Telegram-пользователь может отключить сообщения командой /stop. Состояние кампании и результат по каждому получателю записываются в SQLite.

## Текущий срез реализации

- Существующая VK-функциональность остаётся источником текущей логики объявлений и модерации.
- Telegram onboarding и согласие на получение рассылок реализуются отдельной таблицей.
- Первая итерация Telegram admin panel реализует кампании рассылок. Создание/редактирование объявлений в Telegram и кроссплатформенная публикация идут следующими этапами после унификации идентификаторов пользователей и фото-вложений.
